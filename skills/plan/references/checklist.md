# Plan Review Checklist

> tier 3 资源示例（v26.0）。`skill_view("plan")` 会在 linked_files 里列出本文件，
> agent 判断需要时再 `skill_view("plan", "references/checklist.md")` 按需读取。

提交计划前对照逐项核对：

- [ ] 目标陈述：这次改动要解决的问题用一句话能讲清吗？
- [ ] 范围边界：明确列出「做什么」和「不做什么」，避免范围蔓延。
- [ ] 影响面：列出会触碰的文件/模块，标注可逆性（可逆 / 难逆）。
- [ ] 验证方式：每个改动点对应一条可执行的验证命令或测试。
- [ ] 回滚方案：出问题时如何回退？是否有数据迁移之类的不可逆步骤？
- [ ] 依赖与前置：需要的 env / 服务 / 第三方包是否已就绪？
- [ ] 安全红线：是否触碰认证、删除、生产环境、密钥？触碰则单独标注待确认。
